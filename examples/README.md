# Examples

## Running

```bash
cargo run --example <name>
```

## List

- **basic** - String, number, boolean, email validation
- **object** - Object schemas, required/optional fields, strict mode, nesting
- **array** - Arrays with constraints, nested arrays
- **union** - Enums, mixed types, nullable values
- **advanced** - Tuples, transformations, custom validation, complex structures
- **complete** - User registration validation scenario
